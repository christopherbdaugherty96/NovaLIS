# docs/milestones — Dated completion reports

This folder holds **dated milestone / completion reports** for the personality layer (Phase 1–3
wiring). Each report records what was completed **as of its date**.

**"COMPLETE" / "LIVE" here means "complete at that milestone's date," not a standing runtime
claim.** For what the personality layer actually is now, read the code
(`nova_backend/src/personality/`) and the generated
[`../current_runtime/CURRENT_RUNTIME_STATE.md`](../current_runtime/CURRENT_RUNTIME_STATE.md); for
design intent and audits see `docs/future/PERSONALITY_*` (classified in
[`../future/FUTURE_DOCS_MAP.md`](../future/FUTURE_DOCS_MAP.md)) and `docs/audits/`.

## Contents

- `PHASE_1_PERSONALITY_COMPLETION_REPORT.md`, `PHASE_2_…`, `PHASE_3_…` — per-phase completion.
- `PERSONALITY_WIRING_PHASE_1_REPORT.md`, `PERSONALITY_WIRING_COMPLETE_REPORT.md` — wiring reports.

These are dated evidence, not runtime authority.
